# site/

The PaperKiosk website (https://www.stormwolf.space/paperkiosk/): one static page, no build step for visitors.

- `index.html`, `style.css`: the page. The room scenes are inline SVG around real screenshots (`img/`).
- `fonts.css` and the icon sprite inside `index.html` are generated by `tools/build.py` (see its docstring):
  run it after adding an icon (`<use href="#i-NAME"/>`, any Material Design Icon name).
- `img/`: screenshots from the demo server (`server/tests/demo.py`, see docs/development.md), resized to 720 px
  wide and reduced to 32 greys; `og.png` is the link preview (the hero, 1200 × 630).

It is served by Pages from this folder; public sites there run in a CSP sandbox, hence the inlined fonts and icons.
